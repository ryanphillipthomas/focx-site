# Focx wordmark: INTERNAL / LICENSE PENDING

**Status: INTERNAL / LICENSE PENDING.** "Focx" is set in The Fox Tail Regular (donism / Din Studio), mixed case, as outlines with hand-set spacing and unaltered glyphs. The outlines come from the free personal-use download.
**Do not publish** these files (on a live site, in an app, in social posts, on merch or in any public material) until the commercial licence, Branding & Logo, 1 Brand, **$329**, has been bought. It has not been bought. Internal mock-ups and reviews only.

## Files
| File | Use |
|---|---|
| focx-large-light-ink.svg / focx-large-dark-ink.svg | Large master, for wordmark heights above 32px |
| focx-small-light-ink.svg / focx-small-dark-ink.svg | Small master, for 24 to 32px (o/c opened, c-x join separated) |
| focx-{large,small}-{light,dark}-ink@{1,2,3}x.png | Transparent PNGs. 1x height: large 48px (79px wide), small 24px (43px wide) |

Light ink (#e9e9eb) is for dark backgrounds, which are the default. Dark ink (#17181a) is for light backgrounds. The SVG artwork includes a small margin; "height" means the artwork height.

## Minimum size: DECIDED (Ryan, Oct 15)
- **Minimum 24px tall on screen**, using the small master. That is about 43px wide (the large master would be about 40px wide at 24px).
- **Below 24px, do not use the wordmark.** Write "Focx" as plain text in the system UI font (`font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`).
- Above 32px, use the large master.
- The small size could not get a heavier cut because the free licence forbids altering the glyphs. Revisit after the licence is bought.
